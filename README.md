# Game ToDo

原神・鳴潮のイベント／任務／日課・週課を Obsidian で管理するプラグイン。
前提任務・締切・1日のプレイ時間から優先順位と完了予定を計算し、期限切れで実行できなくなったタスクを削除できます。

## インストール

### 開発する PC

```sh
npm install
npm run build   # または npm run dev（watch）
```

ビルドのたびに、この PC の Obsidian に登録された Vault のうち `.obsidian/plugins/game-todo/` フォルダがあるものへ
`main.js` / `manifest.json` / `styles.css` だけをコピーします（`data.json` は上書きしません）。
使いたい Vault にはそのフォルダを一度作ってください。`OBSIDIAN_VAULTS`（Windows は `;` 区切り）で明示指定もできます。

### 他の PC（BRAT）

```sh
npm version patch   # package.json / manifest.json / versions.json を更新してタグ作成（v なし）
git push --follow-tags
```

タグの push で `.github/workflows/release.yml` がテスト・ビルドし、GitHub Release に3ファイルを添付します。
各 Vault では BRAT プラグインにリポジトリを登録してインストール・更新します。

## タスクノート

1タスク = 1ノート。frontmatter に `gtodo: task` があるノートをどこからでも読み込みます。

```yaml
---
gtodo: task
game: genshin            # genshin | wuwa
kind: event              # event | quest | daily | weekly | periodic | other
start: 2026-10-15T11:00+09:00     # 任意。これより前には予定しない
deadline: 2026-11-04T04:59+09:00  # 任意。日付のみ (2026-11-04) は当日 23:59:59
estimate: 90             # 分。空欄なら Inbox（スケジュール対象外）
remaining: 30            # 任意。残り分（estimate より優先）
suggestedEstimate: 45    # 取り込み時の推定値（参考。スケジュールには使わない）
prereqs:
  - "[[魔神任務 第五章 第三幕]]"
unlock:                  # 取り込み時の参加条件（テキスト）
  - "冒険ランク20以上"
status: todo             # todo | doing | done
url: "https://www.hoyolab.com/article/47008743"   # 取り込み時の元記事（任意）
---
```

## 繰り返しテンプレート

```yaml
---
gtodo: recurring
game: genshin
rule: weekly             # daily / weekly / weekly:thu / monthly:16 / interval:28@2026-09-01
estimate: 30
---
```

起動時と1時間ごとに、現在の期間のインスタンスを `GameTodo/Tasks/<ゲーム>/<テンプレ名> <期間開始日>.md` に作成します。
リセット時刻・UTC オフセット・週リセット曜日は設定でゲームごとに変更できます（既定: UTC+8, 4時, 月曜）。
期限切れの未完了インスタンスは自動でゴミ箱へ移動します（設定でオフ可）。

### 周期コンテンツ（コマンド「周期コンテンツを取り込む」）

決まった周期で更新されるエンドコンテンツなどを、繰り返しテンプレートとしてまとめて作成します。
所要時間は目安を入力済みの状態で表示するので、必要なら直してから取り込んでください（空欄にするとインスタンスは Inbox に入ります）。
取り込むと今期のタスクもすぐ作成します。テンプレートの `url` は各インスタンスにも引き継ぎます。

| ゲーム | コンテンツ | rule | 目安 |
|---|---|---|---|
| 原神 | 深境螺旋 | `monthly:16`（毎月16日 05:00 JST） | 60 分 |
| 原神 | 幻想シアター | `monthly:1`（毎月1日 05:00 JST） | 90 分 |
| 原神 | 週ボス | `weekly` | 30 分 |
| 鳴潮 | 逆境深塔 | `interval:28@2026-09-14`（4週間ごと） | 45 分 |
| 鳴潮 | 死の歌が纏う海の廃墟 | `interval:28@2026-09-28`（4週間ごと、深塔と交互） | 45 分 |
| 鳴潮 | 週間ボス | `weekly` | 15 分 |

- 周期は有志 wiki の 2026-10 時点の記載に基づきます。周期が変わったらテンプレートの `rule` を直してください。
- 原神の「幽境の激戦」、鳴潮の「終焉マトリクス」のように開催期間がバージョンごとに決まるものは rule で表せません。ゲーム内お知らせに載るので「イベントを取り込む」で取り込めます。
- 同じ名前のテンプレート、またはプリセットから作ったテンプレートがある場合は「登録済み」になり、重複して作りません。

## 優先順位の計算

1. 前提任務の締切を逆算（`前提の実効締切 = min(自分の締切, 後続の実効締切 − 後続の所要時間)`）
2. 毎日の「プレイ開始時刻 + 平日/休日の分数」の枠に、実効締切が早い順で割り当て（開始前のイベントは待つ・途中で切り替え可）
3. 完了予定・余裕（slack）を計算し、締切に間に合わないものを赤で表示

両ゲームは同じプレイ時間を共有するものとして計算します（ビューのフィルタは表示のみ）。

## 状態

| 状態 | 意味 | 表示タブ |
|---|---|---|
| active | 予定可能 | 次の枠 / 優先度順 |
| inbox | 所要時間が未設定 | Inbox（その場で分数を入力可） |
| cycle | 前提が循環 | Inbox |
| expired | 期限切れ | 期限切れ（削除可） |
| unreachable | 前提が期限切れ等で実行不能 | 期限切れ（削除可） |
| done | 完了 | 優先度順の「完了」 |

## タスク一覧・検索（コマンド「タスク一覧を開く（検索）」）

サイドバーの表アイコンかコマンドで、メインエリアのタブに全タスクを表形式で表示します。

- **検索**: タイトル・パス・解放条件・警告文・ゲーム名・種類名を対象に部分一致。空白区切りで AND、`-語` で除外（例: `任務 -魔神`）
- **ゲーム / 種類 / 状態**: チップをクリックで切り替え（何も選ばない＝すべて）。状態の「遅延見込み」は締切に間に合わない予定中タスク。既定では「完了」以外を表示
- **期限**: 今日中 / 3日以内 / 7日以内 / 30日以内 / 期限切れ / 期限なし
- **所要 / 前提込み**: タスク自体の所要時間と、未完了の前提任務を含めた合計（前提で増える場合のみ表示）
- **ソート**: 列見出しクリックで並べ替え、再クリックで昇順・降順を反転（値がないものは常に末尾）
- 行クリックでノートを開く（Ctrl/Cmd+クリックで新しいタブ）。チェックボックスで完了切り替え
- 絞り込み条件はタブごとに保存され、Obsidian 再起動後も残ります

## イベント取り込み（コマンド「イベントを取り込む」）

| ゲーム | 取得元 | 備考 |
|---|---|---|
| 原神 | HoYoverse ゲーム内お知らせ（非公式 API、`getAnnList` + `getAnnContent`）の「イベント」グループ | 除外キーワード（既定: 祈願, チャージ, アンケート） |
| 鳴潮 | Kuro Games ゲーム内お知らせ JSON（公式 CDN、イベントタブのみ） | 除外キーワード（既定: パック, アンケート）。URL は設定で差し替え可 |
| 任意 | 設定の JSON フィード URL（`[{"id","title","start","end","url"}]` または `{"events":[...]}`） | |

- お知らせ本文の「イベント期間／開催期間」を解析し、告知の表示期間より優先して `start` / `deadline` にします（`日本標準時` 表記があれば JST、なければサーバー時刻）。`常時開放` は期限なし。
- 本文の「参加条件／開放条件」を `unlock` と本文に保存します。条件中の「…」が既存のタスクノート名と一致すれば `prereqs` にリンクします（「より良い体験」等の推奨文は除く）。

## 任務取り込み（コマンド「任務を取り込む」）

| ゲーム | 取得元 | 対象 |
|---|---|---|
| 原神 | [Project Amber](https://gi.yatta.moe)（`/api/v2/jp/quest`） | 魔神任務・伝説任務・世界任務・イベント任務（1章/幕 = 1タスク） |
| 鳴潮 | [encore.moe](https://encore.moe)（`/ja/story`） | 潮汐任務・連星任務・逸話任務（1話 = 1タスク） |

- 前提任務: 魔神任務は章内の順、各章の第一幕は前章の最後の幕（間章を除く）。伝説任務はキャラごと、潮汐任務は序章からの通し順、連星任務はキャラごとにつなぎます。
  前提が登録済みか同時に取り込む場合だけリンクします。取り込んだ任務を参加条件に引用している既存イベントにも前提リンクを追加します。
- 所要時間: 下の「推定所要時間」の式で `suggestedEstimate` を入れます。

取り込んだノートは `GameTodo/Inbox/` に作成され、所要時間を入れるとスケジュール対象になります。
同じ `source` のノートは重複作成しません。登録済みのノートは、イベントの期限、未記入の参加条件、未確定（`estimate` が空）の推定値だけ更新します。
任務は登録済みでも `estimate` が空なら一覧で選び直せ、選ぶと推定値を再計算します。

## リンク

取り込んだノートには元記事を `url` に保存し、本文末尾の「## リンク」に元記事・関連記事・wiki 検索を並べます。
ビューでは `url` のあるタスクに 🔗 アイコンが出て、元記事を開けます。

| 対象 | 元記事（`url`） | 関連記事 |
|---|---|---|
| 原神イベント | [HoYoLAB](https://www.hoyolab.com) 公式ニュースのうち、お知らせと同じタイトルの記事 | タイトルの「…」内の名前を含む HoYoLAB 記事（最大 5 件） |
| 鳴潮イベント | 公式サイトの同じタイトルの記事。なければ名前を含む記事、それもなければ本文にイベント名がある最近の「コンテンツ紹介」記事（ラベルにその旨を表示） | 「…」内の名前を含む[公式サイトのニュース](https://wutheringwaves.kurogames.com/jp/main/news/)（最大 5 件） |
| 原神の任務 | Project Amber の任務ページ | 任務名を含む HoYoLAB 記事 |
| 鳴潮の任務 | encore.moe のストーリーページ | 任務名を含む公式サイトのニュース |

- 原神も同じタイトルの記事がなければ、名前を含む記事を元記事にします（ラベルにその旨を表示）。
- どれにも有志 wiki（wikiwiki.jp）の検索リンクを付けます。
- ゲーム内のお知らせには Web 上の固有ページがないため、取り込み時にお知らせ全文を折りたたみの引用（`> [!quote]- 元のお知らせ（ゲーム内）`）として本文に保存します。
- 以前に取り込んだノートで `url` がないものは、次の取り込みで `url` を設定し、「## リンク」の先頭に元記事を追記します（節がなければ作成。お知らせ全文は追記しません）。

## 推定所要時間

取り込んだ任務・イベントには推定値（`suggestedEstimate`）を付けます。
推定値は Inbox の入力欄に placeholder として表示されるだけで、✓ ボタンで `estimate` に採用するまでスケジュールには使いません。
ノート本文の「推定根拠」に計算の元を書きます。

| 対象 | 式 | 元データ |
|---|---|---|
| 原神の任務 | `17.2 × 手順数^0.56` 分 | 有志 wiki（[wikiwiki.jp/genshinwiki](https://wikiwiki.jp/genshinwiki/)）の魔神任務 46 幕の「各幕の所要時間の目安」に当てはめた式（中央値で ±20% 程度の誤差） |
| 鳴潮の任務 | `0.082 × 会話文字数^0.74` 分（会話データがなければ `20.3 × 手順数^0.46`） | 有志 wiki（[wikiwiki.jp/w-w](https://wikiwiki.jp/w-w/)）の潮汐任務 42 幕の所要時間に当てはめた式（同 ±16% 程度）。あらすじ（Outline）とルビ記法は数えません |
| イベント | 種類ごとの目安（下表） | 実測データがないため目安値。お知らせのタイトルと本文から種類を判定 |

- 式は 2026-10 時点の wiki の値から作った固定値で、実行時に wiki へはアクセスしません。
- wiki の値はどちらも「ボイスを聞きながら進める」ペースです（鳴潮 wiki は会話をすべて飛ばすと約 1/5 と記載、原神 wiki は迷う初心者向けに長めと記載）。
  設定の「推定所要時間の倍率」（ゲームごと、既定 1）で調整してください。会話を飛ばすことが多いなら 0.5 程度です。
- 当てはめたのはメインストーリー（魔神任務・潮汐任務）だけです。伝説・世界・連星・逸話任務は同じ式で外挿しています。

| イベントの種類 | 目安 | 判定（タイトル／本文） |
|---|---|---|
| ログイン・報酬アップ・キャラ招待・任務連動ボーナス・課金報酬 | 5 分 | ログイン, 2倍, 招待, 期間中に…任務, チャージ |
| 祈願・Web・アンケート・紀行 | 10 分 | 祈願, 確率UP, Web, 予測, 紀行, 先駆ラジオ |
| 戦闘・挑戦・七聖召喚・ミニゲーム・収集・依頼・世界任務・周期コンテンツ | 60 分 | 戦闘, 挑戦, 七聖召喚, ミニ, 収集, 依頼 など |
| 探索・恒常イベント | 120 分 | 探索, エリア, 恒常 |
| 大型イベント | 180 分 | 本文に「第一段階」「第二段階」…や「4つの段階」がある、または報酬が星声 1000 以上（鳴潮） |
| その他 | 90 分 | どれにも当たらない |
いずれの取得元も非公式・第三者のデータのため、仕様変更で取得できなくなることがあります。
